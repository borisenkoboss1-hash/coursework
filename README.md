## Запуск

### Способ 1 — VS Code Live Server (рекомендуется)
1. Установить расширение **Live Server** в VS Code
2. Открыть папку `dveri-rf` в VS Code
3. Правой кнопкой на `index.html` → **Open with Live Server**

### Способ 2 — Python
```bash
cd dveri-rf
python -m http.server 3000
# Открыть: http://localhost:3000
```
